---
title: Last 3 Triples
description: 2LTCP (standard) and TCP / OLP / 1LL3T (advanced).
---

The last 3 triples are solved with **2LTCP** (2-Look Triple Corner Permutation) in the standard path - the beginner path ends here.

The advanced last-layer path is [OLP](/olp/) + TCP, merged by [1LL3T](/1ll3t/).
