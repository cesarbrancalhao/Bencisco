---
title: Last 3 Triples
description: OLP, 2LTCP (standard), and TCP / 1LL3T (advanced).
---

**[OLP](/Bencisco/last-3-triples/olp/)** (One-Look Pair Formation) pairs up the remaining triples before solving them.
 
The last 3 triples are solved with **[2LTCP](/Bencisco/last-3-triples/2ltcp/)** (2-Look Triangle-Corner Permutation) in the standard path; the beginner path ends here.
 
The advanced last-layer path is **[TCP](/Bencisco/last-3-triples/tcp/)** or **[1LL3T](/Bencisco/last-3-triples/1ll3t/)**.
