---
title: Last 3 Triples
description: Pair Formation, 2LTCP (standard), and TCP / OLP / 1LL3T (advanced).
---

**[Pair Formation](/Bencisco/last-3-triples/pair-formation/)** pairs up the remaining triples before solving them.
 
The last 3 triples are solved with **[2LTCP](/Bencisco/last-3-triples/2ltcp/)** (2-Look Triangle-Corner Permutation) in the standard path; the beginner path ends here.
 
The advanced last-layer path is **[OLP](/Bencisco/last-3-triples/olp/)** + **[TCP](/Bencisco/last-3-triples/tcp/)** or **[1LL3T](/Bencisco/last-3-triples/1ll3t/)**.
