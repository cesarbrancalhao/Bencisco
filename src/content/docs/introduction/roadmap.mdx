- **Beginner** - First Block → Remaining 3 Centers → Pair Formation → 2LTCP. Core topics only; skip everything marked **Medium** and **Advanced**. The method is complete at 2LTCP.
- **Intermediate** - optimal solution tables, lookahead, deeper inspection.
- **Medium** - TCP. A manageable subset of 1LL3T.
- **Advanced** - OLP, 1LL3T, EO tracking, cancellations.
